## What is it?

The Beckhoff control platform for [DT_PSA_OPCV](https://github.com/Preliy/DT_PSA_OPCV) — a Unity
digital twin of a laser welding and assembly line, built for virtual commissioning on
[Open Commissioning](https://github.com/OpenCommissioning).

This repository holds the TwinCAT 3 side of it:

| | |
|---|---|
| `PLC_1` | The machine program, built on the SPT (PackML) framework |
| `SIM_1` | The twin's device layer, generated by OC Assistant |
| `HMI` | A TE2000 web HMI for operating the machine |

```
Unity ⇄ SIM_1 ⇄ EtherCAT_1_SIM ⇄ EtherCAT_1 ⇄ PLC_1
```

`PLC_1` never talks to Unity. It talks to EtherCAT terminals, exactly as it would on the real
machine — so the program cannot tell it is running against a twin.

## Who is it for?

- **Goal** — a complete, working TwinCAT program for a realistic machine: seven functional groups,
  interlocks, fault handling and a proper reset model.
- **Why** — learn and test real control code against a machine that behaves like the real thing,
  without owning one.
- **Community driven** — an open, framework-based reference that anyone can study, run and improve.

It is made for **TwinCAT engineers**, **students** learning PackML and the SPT framework, and
**anyone** who wants to see a real line's control program from the inside.

## Getting started

Clone the twin, then this module into its root:

```bash
# step 1: main repo
git clone https://github.com/Preliy/DT_PSA_OPCV.git
cd DT_PSA_OPCV

# step 2: beckhoff modul
git clone https://github.com/Preliy/DT_PSA_OPCV_Beckhoff.git Beckhoff
```

You will need TwinCAT 3 and a PC with **two Ethernet ports** that the TwinCAT real-time driver
supports, joined by a patch cable. Then follow the **[Setup guide](_docs/01-setup.md)** and
**[Usage](_docs/02-usage.md)**.

Everything else is in the **[Documentation](_docs/README.md)**, also browsable as a
**[Wiki](https://github.com/Preliy/DT_PSA_OPCV_Beckhoff/wiki)**. Which version pairs with which twin
is in the main repository's [COMPATIBILITY.md](https://github.com/Preliy/DT_PSA_OPCV/blob/master/COMPATIBILITY.md).

## Contributing

This project grows through discussion. Have an idea, a question or a better way to do something?
[Open an issue](https://github.com/Preliy/DT_PSA_OPCV_Beckhoff/issues) or start a discussion — let's
iterate on it together and make it better.

Directions where help is very welcome:

- **New devices** — drives, barcode readers, and other components real lines use
- **HMI pages** — better screens for operating and diagnosing the machine
- **Hardware-in-the-loop** — running `PLC_1` on a real Beckhoff controller
- **Setup gaps** — for example Unity on a separate host from TwinCAT, which is documented but not yet verified
- **Bugs and corrections** — a report is worth as much as a fix

Two things to know first: new control code follows the
[SPT framework guideline](_docs/reference/spt-framework.md), and changes to sequences, interlocks or
the reset model belong in the [main repository](https://github.com/Preliy/DT_PSA_OPCV/tree/master/_docs/reference),
because every platform has to honour them. See
[CONTRIBUTING.md](https://github.com/Preliy/DT_PSA_OPCV/blob/master/CONTRIBUTING.md).
